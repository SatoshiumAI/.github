# 🔐 Verification Logic Example

Illustration of verification-first processing.

Example logic:

if verify_signature(data, source_key): accept(data) else:
reject("Verification failed")

Principle:

**Verify first. Execute second.**

Verification mechanisms ensure that decisions rely on trusted inputs
rather than authority.
