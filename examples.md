# 🔐 Verification Example (Future Direction)

Illustrative concept of a verification-first agent:

```python
if verify_signature(data, source_key):
    process(data)
else:
    reject("Verification failed")
```

Principle:
**Verify first. Execute second.**

All future Satoshium agents are expected to operate under verifiable logic.
